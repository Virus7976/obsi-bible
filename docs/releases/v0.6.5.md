# Obsi Bible 0.6.5

- Install a Bible from an EPUB. Versions, Install from file. The app finds the books, chapters and verses, so search, highlights and the phone voice work like any other Bible. Only add Bibles you are allowed to use.
- A Voice button in the audio sheet opens the list of voices.
- Better notification: the chapter and Bible name, a cover, previous and next verse, previous and next chapter.
- Headphone buttons step by verse.
