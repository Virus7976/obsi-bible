# Obsi Bible 0.6.0

- Settings has pages now: Bibles and keys, Look, Listening, Obsidian, Updates. Search finds any setting.
- Templates work like ObsiTube. Each template sets the note name, folder, properties and words.
- Each property can use Bible data, a fixed value, stay empty, or ask you when you send.
- When saving: make a new note, save over one, add to the end, or add to the top.
- Use a note from your vault as a template. Changes go both ways.
- Tags on every note: set tags once and every note gets them.
- The send sheet lets you pick a template. Your pick becomes the default.
