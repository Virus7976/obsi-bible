# Obsi Bible 0.5.2

- The reader looks more like a printed Bible: a new book font (Literata), tighter lines, a bigger chapter number.
- Thin outline icons, a back arrow, and a smaller version chip at the top.
- Full screen while reading: the tabs hide when you scroll down and come back when you scroll up.
- Note sheet: a swipe down no longer closes it. It saves while you type, so nothing is lost.
- Note sheet: tags and links sit above the keyboard and scroll into view. The tag box sits in the row with the tags.
- A note with only tags is kept.
