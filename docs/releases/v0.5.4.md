# Obsi Bible 0.5.4

- Full screen while reading also hides the phone's own bars. Swipe from the edge to see them for a moment. The play bar no longer sits under the phone's buttons.
- Tag suggestions come from your vault and from tags you used in the app. Type a few letters to find one.
- Every highlight and note is saved to your vault, one file per book, in Bible/Highlights. It updates when you edit or delete in the app.
- Notes tab: each note shows if it is in the highlights file and if it has its own note.
- Notes tab: tap a note to open it. Hold it to edit, make its own note, copy, share or delete.
- Black look: cards, sheets and bars go black too.
