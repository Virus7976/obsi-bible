# Obsi Bible

Read and listen to the Bible. Look things up fast. Highlight, take notes, and send them to Obsidian.

- Installed Bibles work with no internet.
- Online Bibles (ESV, YouVersion, API.Bible) use your own free key, typed into the app.
- Every note links back to its verse.

Built on the ObsiTube framework. Android 8 and up.
